Privacy Policy

This privacy policy applies to the Fun Math: Math Games app for mobile devices, together with any related services operated by Fun Games & Funny Games (collectively, the "Application"). Fun Games & Funny Games is hereby referred to as the "Service Provider".

Package name: com.fun.best.math.game.funfunnygames


Summary

The Application is a math learning game made for children. It has no accounts or sign-in, does not ask for names, email addresses or any other personal information, does not collect the device advertising ID and does not show ads.

  • The only data that leaves the device is anonymous, aggregated usage and diagnostic information used to improve the game, and the technical requests needed to download game settings.
  • The Service Provider does not sell or share this data with third parties. Google, which runs the services described below, acts only as a service provider for the Service Provider.
  • All data is sent over encrypted connections (HTTPS).


Children and families

The Application is designed for children (ages 5 and under, 6–8 and 9–12) and their families. It is published in line with the Google Play Families Policy and is intended to comply with the Children's Online Privacy Protection Act (COPPA) and similar laws such as the GDPR's rules for children.

  • The Application does not ask children to enter personal information and has no chat, social features, sign-in or links to social networks.
  • No personal information is collected from children. The only identifiers used are random installation identifiers generated by Firebase; they are used solely to support the internal operation of the Application (counting usage, diagnosing crashes and problems, and delivering game settings) and never for advertising, profiling or contacting the child.
  • Purchases and any links that lead outside the game (for example to a website, an app store or videos) open only through a parent area protected by a parental gate that asks an adult to verify before continuing.
  • Ad personalization and advertising features are turned off, and the advertising ID is not collected.
  • If you are a parent or guardian and believe your child has provided personal information, contact the Service Provider at funfunnygames1@gmail.com and it will be deleted.


Usage analytics

The Application uses Google Analytics for Firebase to understand, in aggregate, how the game is played, so that levels and exercises that are too hard or unclear can be improved.

  • What is recorded: anonymous in-app interactions such as which game mode or level is opened, started, finished or left, and the time spent; an app-instance identifier generated for this installation; diagnostic information such as first-open and session events, device model, operating system and app version, and app errors; and an approximate location (country or region) derived from the IP address.
  • What is not recorded: names, email addresses, the advertising ID, payment details or precise location. Analytics data is not used for advertising or ad personalization, and Google signals and ad-personalization features are disabled.
  • This data is used only for analytics, in aggregate, to improve the game. You can stop further collection by uninstalling the Application. How Google processes this data is described in Privacy and Security in Firebase.


Crash reports

The Application uses Firebase Crashlytics to find and fix crashes and performance problems.

  • If the Application crashes or hits an error, a crash report is sent. It contains the crash log (the error and the code location) and diagnostic data such as device model, operating system, app version and a random installation identifier.
  • Crash reports do not contain names, email addresses, the advertising ID or precise location, are used only for debugging and improving stability and performance, and are not shared with third parties. How Google processes this data is described in Privacy and Security in Firebase.


Remote settings and updates

The Application uses Firebase Remote Config to download game settings, for example whether a newer version is available so that an update card can be shown. To do this, Firebase uses a random installation identifier; no personal data is sent. If an update is offered, it is installed through Google Play.


In-app purchase

The Application may offer a single, optional one-time purchase that unlocks the full version. The game can be played without buying anything.

  • The purchase can only be started from the parent area, after an adult passes the parental gate; children cannot start it from the game screens.
  • The purchase is processed entirely by Google Play using Google Play Billing. Card numbers, billing addresses and other payment details are entered in Google Play and never reach the Service Provider.
  • To unlock the full version, the Application receives only the purchase confirmation from Google Play on the device (product, purchase token and purchase status). The Service Provider does not run its own purchase server.
  • Parents can require approval for every purchase in the Google Play settings (purchase authentication) or with Google Family Link. How Google handles payment data is described in the Google Payments Privacy Notice.


Advertising

The Application does not show ads and does not collect the device advertising ID (AAID). If this ever changes, this policy will be updated before the change takes effect, and only ads certified for the Google Play Families program will be used.

  • Data required for legal compliance: retained as long as required by applicable law.
